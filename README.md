# Clip → PDF

CLIP STUDIO PAINT を立ち上げずに、`.clip` から PDF と PNG を作るブラウザアプリです。

**https://manga-tools.github.io/clip2pdf/**

`.clip` をドラッグするだけで、中に保存されているプレビュー画像を取り出して 1 つの PDF にまとめます。ネームの確認やページ順の共有を、アプリの起動を挟まずに済ませるためのものです。

## 特徴

- **ブラウザの中だけで完結**します。ファイルはどこにも送信されません。サーバーもありません
- **ページ幅が揃います**。`.clip` のプレビューはキャンバスの縦横比によって解像度が変わるため、単純に並べると PDF のページ幅がばらつきます。ページごとに寸法を計算して幅を統一しています
- **トンボの内側で切り出せます**。`.clip` に保存されている仕上がりサイズ・裁ち落とし幅を読んで、キャンバス全体／仕上がり／仕上がり＋裁ち落としを選べます
- **無変換で出力できます**。プレビューは PNG で保存されているので、切り出しを使わない場合は再エンコードせずそのまま PDF に埋め込みます。JPEG を選べばサイズを 1/3〜1/8 に落とせます
- 複数ファイルの並べ替え、ZIP でのまとめ出力に対応しています

## 使い方

1. 上のリンクを開く
2. `.clip` をドラッグ＆ドロップ（複数可・フォルダごとでも可）
3. 範囲と画質を選ぶ
4. 「PDF を保存」または「画像を ZIP で保存」

Chrome / Edge では保存先を選ぶダイアログが出ます。Safari / Firefox は API が無いため、ダウンロードフォルダに保存されます。

うまく動かないときは「診断」ボタンを押すと、どこで止まっているかが分かります。

## 制限

- **取り出せるのはプレビュー画像だけ**です。原寸のレイヤー合成結果ではありません。解像度はキャンバスの縦横比に依存し、極端に縦長のファイル（webtoon など）では 30dpi 程度まで落ちることがあります。コマ割りの確認には使えますが、セリフを読む用途には向きません
- **古い `.clip` にはトンボ情報がありません**。CLIP STUDIO のバージョンによって内部のテーブル構成が異なるため、情報が無いファイルは自動的にキャンバス全体になります（画面上に「トンボ情報なし」と表示されます）
- 極端に縦長のページは、PDF の 1 ページ上限（14400pt = 5080mm）に収まるよう幅を自動で縮めます

## 技術的なこと

`.clip` は CSFCHUNK 形式で、内部に SQLite データベースがそのまま埋め込まれています。プレビュー PNG は `CanvasPreview.ImageData` に BLOB として入っており、SQLite のページ境界で分割されるため、ファイルをバイト走査しても取り出せません。`CHNKSQLi` チャンクから DB を切り出して SQL で読む必要があります。

コンテナのサイズ値は 64bit ビッグエンディアン固定で、SQLite 自体もプラットフォーム非依存のため、Windows で作成された `.clip` でも同じように扱えます。

依存ライブラリは `vendor/` に同梱しています（CDN に依存しません）。

- [sql.js](https://github.com/sql-js/sql.js) — MIT。wasm を base64 で JS に埋め込んであるため、`file://` で開いても動作します
- [jsPDF](https://github.com/parallax/jsPDF) — MIT
- [JSZip](https://github.com/Stuk/jszip) — MIT / GPLv3

## 注意

CLIP STUDIO PAINT のファイル形式の解析は非公式です。セルシス公式のツールではありません。将来のバージョンで形式が変わり、動作しなくなる可能性があります。
